We are adding an entirely new screen to Pixel Focus.

This screen does NOT exist today.

It will become the default screen users see when they open the application.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

This is NOT a dashboard.

This is NOT an analytics page.

This is the HOME.

Think of it as the operating system's desktop.

Everything important starts here.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

The goal is simple.

When a student opens Pixel Focus they should instantly know:

• What should I do next?
• How much have I done today?
• What deserves my attention?
• Can I immediately begin studying?

Without opening another page.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Pixel Focus contains many modules.

Tasks.

Calendar.

Pomodoro.

Analytics.

Study Planner.

Mock Tests.

Music.

Settings.

I DO NOT want users constantly jumping between them.

Instead, Home should intelligently surface the most useful information from every module.

The detailed pages still exist.

Home is simply the command centre.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Imagine this sentence guiding every design decision:

"If an operating system was designed exclusively for ambitious students."

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

The experience should feel calm.

Confident.

Focused.

Opening Pixel Focus should reduce anxiety.

It should never overwhelm the user.
