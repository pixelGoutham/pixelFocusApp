1. AUDIT SCOPE
This audit examines the PixelFocusApp codebase to determine what data the application collects, stores, transmits, and processes. The audit focuses on the Electron desktop application being prepared for Microsoft Store submission, built from the source code in the `focusforge-desktop` directory.

- Main Entry Point: focusforge-desktop/main.js
- Production Build Path: focusforge-desktop/release/ (electron-builder output)

3. EXECUTIVE SUMMARY
Pixel Focus is an offline-first productivity application that stores all user data locally by default. The application offers optional cloud synchronization via Firebase when users sign in with Google or Apple accounts. Key privacy-relevant features include:
- Local storage of tasks, study sessions, flashcards, mock tests, and settings in IndexedDB
- Optional Firebase-based cloud synchronization (requires user authentication)
- Discord Rich Presence integration that transmits user activity data to Discord
- YouTube integration for music streaming that fetches metadata from YouTube's oEmbed API
- Standard web technologies with no evidence of hidden tracking, fingerprinting, or unauthorized data collection
- The application functions fully offline without requiring an account
