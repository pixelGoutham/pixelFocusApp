# Privacy Policy for Pixel Focus

**Effective Date:** September 29, 2026  
**Last Updated:** September 29, 2026  

## 1. Introduction
Pixel Focus ("we", "our", or "the application") is a productivity and focus application designed for students and general users. This Privacy Policy explains how we handle information when you use our Windows desktop application distributed via the Microsoft Store.  
By using the application, you consent to the practices described in this policy.

## 2. Information We Collect
We collect only the information you voluntarily provide or that is generated by your use of the application. We do not collect any information automatically or without your knowledge.

### Information You Provide Directly
- **Account Information:** If you choose to sign in with Firebase authentication, you may provide an email address, password, display name, and profile photo URL to your chosen identity provider (Google, Apple, or email/password). We receive only a Firebase user ID (UID) and, if provided by the provider, your display name and email address. We do not access or store your password.
- **Voluntary Submissions:** Any text, notes, tasks, study sessions, flashcards, mock-test data, settings, or preferences you enter into the application are stored locally on your device and are only transmitted externally if you explicitly enable cloud synchronization.

### Information Generated Automatically by the Application
- **Application Usage Data:** The application generates timestamps, counters, and internal state (e.g., pomodoro timer values, theme preference) solely for local functionality. This data is not transmitted externally unless you enable cloud synchronization.
- **Discord Rich Presence Data:** If you connect your Discord account, the application sends non-personal activity information (described in Section 5) to Discord's Rich Presence API. This data does not include your Discord username, email, or any personal identifiers.

## 3. Information Stored Locally
All application data is stored locally on your device using IndexedDB (via the localForage library) unless you opt into cloud synchronization. The following categories of data are stored locally:
- Tasks, to-do lists, and reminders
- Study session logs and timers
- Flashcard decks and study materials
- Mock test results and answers
- Application settings and preferences (theme, notifications, shortcuts, etc.)
- Music synthesizer presets and compositions (offline Web Audio API)
- Local cache of any synchronized data (if synchronization is enabled)
- Firebase user ID (UID) and associated authentication tokens (if you sign in)

**Important:** Local data is **not encrypted at rest**. The application relies on the security of your device and operating system to protect stored data.

## 4. Account and Cloud Synchronization
Pixel Focus offers optional cloud synchronization via Firebase. This feature is **disabled by default** and must be explicitly enabled by you through the application settings.

### What Is Synchronized
When you enable cloud synchronization and are signed in, the following data may be transmitted to Firebase:
- Your Firebase user ID (UID)
- Your email address and display name (if provided by the identity provider)
- Any locally stored data you choose to sync (tasks, study sessions, flashcards, mock-test data, settings, etc.)
- Timestamps indicating when data was last modified

### What Is Not Synchronized
- Your password (never transmitted to or stored by Pixel Focus)
- Any data you have not explicitly chosen to sync (all data remains local by default)
- Information sent to Discord Rich Presence (see Section 5)

### Controls
You may disable cloud synchronization at any time in the application settings. Disabling synchronization stops further transmission of data to Firebase but does not delete data already stored in your Firebase project. To delete data from Firebase, you must use the Firebase console or client tools associated with your Firebase project.

## 5. Discord Rich Presence
If you choose to connect your Discord account, Pixel Focus uses the Discord Rich Presence API to display your current activity (e.g., studying, on a break, listening to music) on your Discord profile.

### What Is Transmitted
When Discord Rich Presence is active, the application sends the following information to Discord:
- `details`: A short string describing your current activity (e.g., "Studying", "On Break", "Listening to Music")
- `state`: A longer string providing additional context (e.g., "Pomodoro Session", "Break Time", "Synthesizer: Piano")
- `startTimestamp`: The Unix timestamp when the current activity began
- `largeImageKey`: Fixed value `"logo_dark"` (refers to an asset embedded in the application)
- `largeImageText`: Fixed value `"PixelFocus"`
- `instance`: Set to `false`

No personal data, Discord identifiers, IP addresses, or application usage metrics beyond the activity description are transmitted.

### Controls
You may disable Discord Rich Presence at any time in the application settings. Disabling it stops all transmission of data to Discord.

## 6. Third-Party Services
Pixel Focus integrates with the following third-party services. Their own privacy policies govern the processing of information they receive.

### Firebase (Google)
- **Purpose:** Optional authentication and cloud synchronization.
- **What We Send:** Firebase user ID (UID), email address, display name (if provided), and any data you opt to synchronize.
- **What They Process:** According to Google's Firebase privacy policy, Google processes this information to provide authentication, database storage, and synchronization services. Refer to [Firebase Privacy Policy](https://firebase.google.com/support/privacy) for details.
- **Your Controls:** You may sign out at any time to stop further synchronization. Data already stored in your Firebase project remains subject to your Firebase account settings.

### Discord
- **Purpose:** Optional Rich Presence integration to show your activity on your Discord profile.
- **What We Send:** Non-personal activity strings, timestamps, and fixed identifiers (see Section 5).
- **What They Process:** According to Discord's Privacy Policy, Discord processes this information to display your Rich Presence. Refer to [Discord Privacy Policy](https://discord.com/privacy) for details.
- **Your Controls:** You may disconnect your Discord account at any time in the application settings to stop transmission.

### Electron Framework
- **Purpose:** The application is built with Electron, which provides the desktop runtime environment.
- **What We Do:** We configure Electron with security-best-practices: `contextIsolation: true`, `nodeIntegration: false`, `sandbox: true`, and we disable unnecessary permissions. Electron does not receive or process your application data beyond providing the execution environment.

## 7. How We Use Information
We use information solely to provide the application's core functionality:
- Local data enables features such as task management, timers, music synthesis, and settings persistence.
- Firebase UID and authentication tokens allow optional sign-in and cloud synchronization.
- Discord Rich Presence data allows your Discord profile to reflect your current activity within the application.
- We do not use information for advertising, profiling, marketing, or any purpose unrelated to providing the application's functionality as described.

## 8. How Information Is Stored and Secured
- **Local Storage:** Data is stored in IndexedDB/localForage files within the application's user data directory. No encryption is applied at rest.
- **Transmission:** All data sent to Firebase or Discord is transmitted over HTTPS (TLS 1.2 or stronger).
- **Application Security:** The Electron application is built with the following security settings:
  - `contextIsolation: true`
  - `nodeIntegration: false`
  - `sandbox: true`
  - `webSecurity: true` (default)
  - `disableBlinkFeatures: "Auxclick"` (to reduce attack surface)
- **No Encryption at Rest:** As stated, local data is not encrypted. We rely on device-level security (e.g., BitLocker, filevault, user account permissions) to protect stored data.

## 9. Data Retention
- **Local Data:** Retained until you delete it via the application's data-clearing features or uninstall the application. Uninstalling the application removes all local data.
- **Firebase Data:** Retained according to your Firebase project's retention settings and your actions within Firebase. Pixel Focus does not impose a retention schedule on your Firebase data.
- **Discord Data:** Discord retains Rich Presence data only for the duration of your session or until you update your activity; Discord's own policies govern their retention.

## 10. Your Choices and Data Controls
You have the following controls over your information:
- **Sign In/Sign Out:** You may sign in or out of Firebase authentication at any time via the application settings.
- **Cloud Synchronization:** Toggle on or off in settings. When off, no data is sent to Firebase.
- **Discord Rich Presence:** Toggle on or off in settings. When off, no data is sent to Discord.
- **Delete Local Data:** Use the application's "Clear Data" or "Reset" features (where available) to remove locally stored tasks, sessions, settings, etc. Note: This does not affect data already synchronized to Firebase.
- **Export Data:** Where provided, use export features to save copies of your data locally before deletion.
- **Application Uninstall:** Uninstalling the Pixel Focus application from Windows removes all local application data stored by the application.

## 11. Data Deletion
- **To Delete Local Data:** Use the in-app data clearing options (if available) or uninstall the application.
- **To Delete Firebase Data:** You must manage your Firebase project directly (via Firebase console, CLI, or client SDK) to delete your user data or disable your account.
- **To Stop Discord Transmission:** Disable Discord Rich Presence in the application settings; Discord will cease to show your activity from Pixel Focus.

## 12. Children's and Students' Privacy
Pixel Focus is designed as a general productivity aid and may be used by students of all ages. We do not knowingly collect personal information from children under 13 without verifiable parental consent. However, because the application does not require account creation for core functionality and does not collect personal data by default, we consider the risk of unintentional collection from children to be low.  
If you are a parent or guardian and believe your child has provided personal information to the application, please contact us at pixelgoutham@gmail.com to request deletion.

## 13. Offline Use
The core functionality of Pixel Focus (task management, timers, music synthesizer, flashcards, settings) operates fully offline. An internet connection is required only for:
- Signing in with Firebase authentication
- Enabling or using cloud synchronization
- Using Discord Rich Presence (requires internet to reach Discord's API)
- Checking for application updates (handled by Microsoft Store)
