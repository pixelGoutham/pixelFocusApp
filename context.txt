# PixelFocusApp Project Summary
meow T_T
## Overview
PixelFocusApp is a productivity and focus application designed for students. It provides a suite of tools to help with studying, time management, and organization. The application is available as a web app and can be packaged as a standalone desktop application for Windows, macOS, and Linux using Electron.

## Technology Stack
- **Frontend**: React 19, Vite, TypeScript, Tailwind CSS
- **State Management**: React Context (Auth, Store, Music, Timer, Theme), React Query (TanStack Query)
- **UI Components**: Radix UI, Framer Motion, Lucide Icons, Sonner Toast, Recharts, Embla Carousel, @phosphor-icons/react
- **Build Tools**: pnpm (monorepo manager), esbuild, TypeScript
- **Desktop**: Electron, electron-builder
- **Backend**: Node.js, Express, Drizzle ORM, Firebase (for authentication and data sync)
- **Database**: LocalForage (IndexedDB) for offline storage, with potential sync to Firebase
- **Other**: Zod (schema validation), HookForm, Date-fns, Wouter (routing), clsx, class-variance-authority, discord-rpc, youtube-iFrame API

## Project Structure
The project is a pnpm monorepo with the following key directories:

```
/artifacts
  /focusforge        - Main web application (React/Vite)
  /api-server        - Node.js/Express API server
  /mockup-sandbox    - Tool for creating/previewing UI mockups
/lib
  /api-client-react  - React hooks/components for API communication
  /api-spec          - API specifications (OpenAPI/Swagger)
  /api-zod           - Zod schemas for API validation
  /db                - Database layer and Drizzle ORM schemas
/scripts             - Utility scripts (e.g., hello world example)
/focusforge-desktop  - Electron wrapper for desktop builds
/focusforge-desktop-linux - Linux-specific Electron build variant
/attached_assets     - Screenshots, design assets, and notes
/node_modules        - Dependencies
/pixel-builds        - Build outputs (Android, desktop-source, linux, windows)
```

## Subproject Details

### artifacts/focusforge
The core application built with React and Vite. It includes:
- Multiple context providers for global state (Auth, Store, Music, Timer, Theme)
- Routing with Wouter (hash-based for Electron, browser history for web)
- Integration with Firebase (via package.json dependencies) for authentication and data sync
- Offline capability using localforage
- Responsive design with Tailwind CSS
- Features like drag-and-drop panels, modals, toast notifications, etc.
- Comprehensive UI component library built with Radix UI and Tailwind CSS
- Apple Design System implementation throughout the interface
- Discord Rich Presence integration showing current pomodoro state and music listening
- YouTube-integrated music player with background audio capabilities

### artifacts/api-server
A Node.js/Express server that provides API endpoints for the application. It uses:
- Drizzle ORM for database interactions
- Pino for logging
- CORS and cookie-parser middleware
- Workspace dependencies: @workspace/api-zod and @workspace/db
- RESTful API design with proper error handling

### artifacts/mockup-sandbox
A Vite-based React application likely used for designing and previewing UI mockups or components. It includes:
- Similar UI library dependencies as focusforge
- Additional tools like chokidar (file watching) and fast-glob
- A custom mockupPreviewPlugin.ts
- Component library preview and testing capabilities

### focusforge-desktop
An Electron wrapper that packages the focusforge web application into a desktop executable. It uses:
- electron-builder to create platform-specific installers (.exe, .dmg, .AppImage)
- Built web assets from the focusforge application (served via file:// protocol)
- Main process (main.js) and preload script (preload.js) for Electron integration
- Data persistence in IndexedDB (via localforage) stored in the user's app data folder
- Custom application icons (logo_dark.ico for light themes, logo_light.ico for dark themes)
- System tray integration and native menu support
- Cross-platform compatibility (Windows, macOS, Linux)

### focusforge-desktop-linux
A Linux-specific variant of the Electron wrapper, likely used for AppImage builds and Linux-specific packaging configurations.

### lib/* (Shared Libraries)
- **api-client-react**: Contains React hooks and components for consuming the API server.
- **api-spec**: Contains API specifications (possibly OpenAPI/Swagger) for defining endpoints.
- **api-zod**: Contains Zod schemas for request/response validation and type safety.
- **db**: Contains database schema definitions and Drizzle ORM setup.

### scripts
Utility scripts for development tasks, currently containing a simple "hello" TypeScript example and post-merge hook.

## Notable Aspects
1. **RTK (Rust Token Killer)**: The project uses RTK as a Claude Code hook to reduce token consumption when interacting with the AI assistant by filtering bash command output.
2. **Monorepo Management**: Uses pnpm workspace with package cataloging for consistent dependency versions across packages.
3. **Offline-First Design**: The application stores data locally using IndexedDB (via localforage) and can work offline, with potential sync to Firebase when online.
4. **Cross-Platform Desktop**: The focusforge-desktop directory shows how the web app is packaged into native desktop installers for major operating systems.
5. **Security Conscious**: The pnpm-workspace.yaml includes a minimumReleaseAge setting (1440 minutes) as a supply-chain attack defense.
6. **Asset Directory**: The attached_assets directory contains screenshots, design notes, and experimental integrations (e.g., Gemini AI integration experiments).
7. **Discord Integration**: Rich Presence integration that displays user's current activity (pomodoro state, music listening) on Discord.
8. **Apple Design System**: Comprehensive implementation of Apple's design principles throughout the UI, including:
   - Fluid typography with CSS clamp()
   - Optical sizing and variable fonts
   - Interruptible springs for animations
   - Momentum and spatial consistency
   - Adaptive color schemes and materials
   - Theme-aware UI components
   - Subtle focus states replacing harsh outlines
   - Proper elevation and depth effects
9. **YouTube Music Integration**: Headless YouTube player for background audio playback with search and metadata fetching capabilities.
10. **Comprehensive Timer System**: Includes Pomodoro timer, stopwatch, and lap tracking with persistence.

## Build and Development
- **Web App**:
  - dev: `pnpm --filter @workspace/focusforge run dev`
  - build: `pnpm run build` (builds all packages)
- **Desktop**:
  - Navigate to focusforge-desktop and run `npm install` then `npm run build:win` (or mac/linux)
  - For Linux AppImage: `npm run build:linux`
  - For Windows installer: `npm run build:win`
  - For macOS DMG: `npm run build:mac`
- **API Server**:
  - dev: `pnpm --filter @workspace/api-server run dev`
- **Clean Build Sequence**:
  ```
  # 1. Clean web app artifacts
  rm -rf artifacts/focusforge/dist

  # 2. Clean Electron web assets (ensures fresh copy)
  rm -rf focusforge-desktop/electron-web/*
  rm -rf focusforge-desktop-linux/forge-desktop/electron-web/*

  # 3. Rebuild React web application
  cd artifacts/focusforge && pnpm install && pnpm run build

  # 4. Copy built assets to Electron directory
  cp -r artifacts/focusforge/dist/public/* focusforge-desktop/electron-web/
  cp -r artifacts/focusforge/dist/public/* focusforge-desktop-linux/focusforge-desktop/electron-web/

  # 5. (Optional) Clean previous Electron builds
  rm -rf focusforge-desktop/release/* focusforge-desktop/dist/*
  rm -rf focusforge-desktop-linux/forge-desktop/release/* focusforge-desktop-linux/forge-desktop/dist/*

  # 6. Build Linux AppImage (portable, single-file)
  cd focusforge-desktop && npm run build:linux
  # Output: release/Pixel-1.0.0.AppImage (~120MB)

  # Alternative: Build Windows ZIP (for sharing)
  # cd focusforge-desktop && npm run build:win
  # Output: release/Pixel-x64.zip
  ```
- **Quick Test Commands**:
  ```
  # Test Linux AppImage
  chmod +x focusforge-desktop/release/Pixel-1.0.0.AppImage
  focusforge-desktop/release/Pixel-1.0.0.AppImage

  # Test web app directly (development)
  cd artifacts/focusforge && pnpm dev
  ```

## Technical Details (Selected Implementation Highlights)
- **Fluid Typography**: --font-size: clamp(0.875rem, 0.5rem + 0.75vw, 1rem)
- **Optical Sizing**: font-optical-sizing: auto applied to html element
- **Size-specific Tracking**: --tracking: 0em, --tracking-heading: -0.02em
- **Inverse Leading**: --leading: 1.5, --leading-heading: 1.1
- **Accessibility Media Queries**: prefers-reduced-motion, prefers-reduced-transparency, prefers-contrast
- **Drag Physics**: Velocity tracking (pixels/second), rubberband() progressive resistance
- **Button Animations**: Critically damped Framer Motion springs (bounce: 0, duration: 0.4)
- **Overlay Positioning**: Removed fixed positioning overrides, let Radix UI handle natural anchor-based positioning
- **Discord Rich Presence**: Shows pomodoro phase (focus/break/longBreak) and current music track
- **YouTube Integration**: Headless player using iframe API, metadata fetching via youtubei.js inference
- **Apple-Inspired Focus Styles**:
  - Light mode: White background with zinc-400 border
  - Dark mode: Semi-transparent white background ([0.08]) and border ([0.3]) with smooth transitions
- **Theme System**: Automatic detection of system preferences with manual override capability
- **Persistence**: All user data stored in IndexedDB via localforage, with optional Firebase sync
- **Electron Security**: Sandbox enabled, nodeIntegration disabled, context isolation enabled
- **Asset Handling**: Relative paths for proper resolution in both web (http://) and Electron (file://) contexts
