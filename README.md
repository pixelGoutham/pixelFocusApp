I started preparing for JEE and well the time crunch was real and the college hours were exhausting(Basically the entire day time),
So to organize my life Pixel Focus started

After some time, I started getting frustrated by how little control I had over the app development and how it was not **Mine**.
Then I imported all the files into VS code on my laptop, stripped away all the AI Slop, and starting the development arc(xD).

1. A single source of truth subject manager and data handling using IndexedDB
2. Apple inspired clean and minimal UI(just mwah)
